# F1.2 片库筛选与排序面板

日期：2026-10-23（Asia/Shanghai）。用户已确认扩展现有排序面板；本批完成基础筛选接入和返回恢复，不代表评分区间、任意年份或搜索服务端分页已经支持。

## 行为

- “筛选与排序”面板提供媒体类型、题材、年代、已看／未看，保留标题／评分／发行年份／添加日期排序及升降序。类型按媒体库类别提供，题材与年代使用当前片库标签接口返回的可用项；题材名称来自官方中文题材表，不硬编码 ID 名称映射。
- 草稿与已应用条件分离。取消、关闭与 Esc 不改变列表；重置恢复面板中的空筛选与添加日期降序，点击应用后生效。应用把筛选与排序合并成一次列表请求，从第 1 页加载；已应用条件和数量可在列表页查看。
- 列表请求继续使用 `POST /v/api/v1/item/list`：type 数组、genres 单个数值 ID、decade 官方代码、watched 字符串 0／1；未选择字段省略。没有添加未经核实的评分区间或任意起止年份参数。
- 改条件前取消旧列表；失败保留旧卡片并明确标识为上次结果，暂停翻页，重试仍使用失败的目标页。空结果区分“无匹配影片”和“空媒体库”，不伪装成功或把旧卡片当作新筛选结果。
- 按活动账户与媒体库保存最多 12 条视图，包含已应用条件、排序、页码、当前页结果、选项名称和实际内容容器位置。详情／播放器返回时先恢复，再后台验证同页；验证期间滚动不回拉。草稿对象和选项对象复制，未应用编辑不污染已保存状态。
- 元数据请求在切库、离开或关闭面板时取消；迟到响应不覆盖新片库。失败可重试；题材名称失败时保留其他筛选选项。弹层限制视口宽度与高度，窄屏单列表单；真实设备布局仍需验收。
