# 媒体权限、数据保留与 PC 播放扩展

## 本批行为

- 共享配置和辅助记录核查当前飞牛账号媒体权限，分集核查真实季度归属；旧共享写入仅管理员可用，普通用户界面只读，个人来源绑定不受影响。
- 远程直链在使用 NAS 挂载凭据前核实当前媒体、文件 GUID 与精确路径；Alist 会话改为请求独享。直链失败时继续使用已有飞牛链接，不把整个视频初始化变成失败。
- 自动弹幕匹配不再写入家庭共享链接，改为按账号／来源配置版本／媒体隔离的有界缓存。电影的官方第 0 集字段统一映射到弹幕第 1 集，手动选择、自动加载、表情和调度保持一致。
- 辅助记录保留工具默认只读，执行前必须备份，不安装自动清理任务，本批不清理生产历史。具体边界见 [数据策略](DATA-SCOPE-AND-RETENTION.md)。
- PC 浏览器设置增加画中画与睡眠定时。画中画按真实 API 能力显示；仅原生视频，不承诺网页文本／ASS／PGS／弹幕覆盖层进入浮窗。定时可选 15／30／60／90／120 分钟或播完本集停止，可取消、跨集计时，离开页面／切换账号清理；到期暂停并阻止自动连播。系统休眠可能延迟执行，页面恢复会检查真实截止时间，不控制外部播放器。
- 关闭与本集停止／自动连播冲突的 ArtPlayer 单片循环；初次播放 Promise 拒绝有收尾，定时已过期时不自动启动迟到的播放器实例。

API 能力依据：[requestPictureInPicture](https://developer.mozilla.org/en-US/docs/Web/API/HTMLVideoElement/requestPictureInPicture)、[后台页面计时限制](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)。不支持或权限拒绝时保留正常网页播放，不能将 API 存在当成电视投屏能力。
