# F1.3 收藏与观看状态页面发布

日期：2026-10-23（Asia/Shanghai）。用户已确认“详情操作＋收藏入口”方案。独立待看没有对应已确认接口，仍未实现，不将收藏改名为待看。

## 本批功能

- 电影／剧集详情增加收藏与取消收藏；电影详情和季内单集提供已看／未看。收藏先读取服务端当前状态再允许切换，观看状态使用明确的目标动作。单集操作与播放按钮分离，不改变分集点击播放的目标。
- App 统一持有账户化写入助手。同项重复点击复用请求，反向在途写入拒绝；只接受共用请求层校验过的成功响应，不自动重试。更新后重新读取官方状态；拒绝、结果未确认和成功后读取失败分别展示。账号变化与页面离开不会把旧响应写入新页面。
- 侧栏收藏使用 `/list?scope=favorites`，复用列表的筛选、排序、有限分页和返回恢复。收藏与各片库的状态分别保存，内部 @favorites 缓存键不发送给服务端；收藏列表走 favorite/list、标签范围使用 is_favorite=1。收藏导航按明确查询范围高亮，关闭 Vue Router 默认忽略 query 的激活样式。
- 本季批量操作先展示明确分集清单与实际目标数，取消不发送写入。校验当前季 ID、分集归属与已知总数，分集不完整、范围改变或超过 1000 项时拒绝；不猜测提交季 ID 的递归效果。两并发逐集处理，展示接受、失败／未确认、未执行数量及具体失败分集；停止后不再启动新任务，等待已发出请求完成，结束后整体刷新。离开页面停止后续任务，已发生的服务器操作仍会使相关缓存失效。
- 状态变更统一取消旧栏目请求、失效列表结果和详情快照、重新验证搜索；保留筛选／页码／位置、继续观看快照及已有图片。未核实的受影响标记先隐藏，后台读取后恢复；当前列表会同页重验、必要时回退有效页。首页只重新加载已可见栏目，保持原并发上限；旧详情不再把修改前的状态存回快照。

## 回退

回退整个 F1.3 时，按 [静态回退流程](../deploy/README.md) 使用 **132756 备份的 web-before/ 与 previous-web-manifest.json** 恢复原筛选版，再按该批 source_files 列表从 frontend-before/ 逐项恢复 21 个配套文件；新增的 media-actions.js、media-state-cache.js 及两项新回归文件可移除。不要把 133006 的 web-before/ 当作 F1.3 前版本，它只对应导航修正前的功能首版。

静态回退不需重启容器、回退后端索引或恢复本地数据库；也不撤销用户在飞牛服务端已经确认的收藏／观看状态。实际网页回退前应另备份当时版本，保留旧散列资源供已打开页面加载。
