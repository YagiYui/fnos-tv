# 各平台原文件外部播放

## 问题与改动

此前 Windows 外部播放使用原文件，其他平台仍创建独立 HLS 会话。已有真实链路证据显示官方 HLS 在约 65–75 秒后可能回收，4 小时代理票据无法延长官方会话。继续轮询清单、checkPlayLink 或转码统计不能证明保活。

本批将网页正常外部入口统一为已实现的受限原文件链接，保留当前远程直链；不再按系统创建 HLS 会话。准备原文件只需读取官方流列表并核对选定文件，不依赖 play/info、play/quality、网页可解码轨道或新建 play/play。所选文件已删除时明确失败，不悄悄切到其他版本。请求开始前和响应后均检查取消。后端既有身份／文件归属与单字节 Range 验证仍生效，没有新增后端接口。

外部弹窗按现有平台映射显示适用入口，保留 PotPlayer 下载 m3u 与复制 HTTP 地址的既定设计，没有修改 Windows 协议或关联。提示明确：音轨、内嵌字幕和位置由外部应用选择，网页画质、字幕偏移及本地导入字幕不会自动传入；无法解码原文件可返回网页播放。原文件地址具有时效，不能公开分享。不承诺外部应用自动续播或进度回传。

旧 HLS 票据接口和显式内部 HLS helper 路径继续兼容，正常网页入口不再使用；这不表示旧 HLS 的会话存活问题已修复。

## 验证

- 前端 47 项通过、1 项真实 PGS 素材检查跳过；构建通过，仅既有大包提示。
- 独立 Edge 的 Windows、macOS、Android、iPad 桌面 UA、Linux 五种模拟环境：真实 Vue 页面选择第二个文件，外部请求只携带该 item_guid／media_guid；不新建网页会话，不查询网页质量，不覆盖原网页链接；模拟 play/play 失败时仍能准备原文件链接；平台入口、窄屏弹窗和无页面脚本错误通过。
- 单元回归覆盖缺少文件、所选文件删除、开始前取消、迟到响应取消及显式旧 HLS 兼容。模拟环境未启动任何原生播放器，不能据此宣称手机或桌面应用解码通过。
- 本次无可用的正式临时票据，未提取账号凭据或创建真实播放会话。此前同一原文件后端实现的 90 秒 Range 与 85 秒 FFmpeg 证据仍是历史链路证据，不替代本批跨平台真机验收；新增 P22 保留待验证。
