# 多文件、字幕调整与播放诊断

本批继续用户“直到 TODO 全部完成”的既有范围，不等待重复交互确认。实现与人工验收分别记录。

- 播放设置提供“版本／文件”，只显示文件名和实际规格。轨道以 media_guid 分组，画质按所选文件重新请求。多文件无归属轨道不猜测；单文件兼容旧响应。切换默认从头，勾选才继续当前时间，保留暂停。恢复、外部播放与 302 使用所选文件。
- 时间偏移 -60 至 60 秒，正值延后，支持文本、ASS 和 PGS；字号、距底部和阴影仅调整普通文本。调整只在当前文件／本次页面有效，切文件／切集清除。
- 本地导入 UTF-8 SRT／VTT，最大 2 MB、50000 条，去除 HTML／样式、校验时间。不上传、不保存，切集／换文件／重开／切账号清除。本地 ASS／PGS 导入和双字幕未包含，已有服务器 ASS／PGS 保留。
- 诊断可刷新／复制：缓冲、媒体状态、源编码、请求质量、取得时的 HLS 实际参数、错误代码／分类。没有可信依据时转码状态 unknown。导出字段白名单，不含片名、路径、ID、账号、原始错误、请求、URL 或凭据。
