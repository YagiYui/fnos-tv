## 已实现的数据契约

| 项目 | 默认值 | 接受值 |
| --- | --- | --- |
| audioLanguage | 空字符串 | 最多 64 字符，无控制字符的语言标识；实际匹配仍由音轨模块决定 |
| autoPlayNext | true | 布尔值 |
| assSubtitles | true | 布尔值 |
| subtitleFontSize | 20 | 12–60 的整数 |
| playbackRate | 1 | 0.5–3 的有限数值 |
| use302 | false | 布尔值 |

沿用 `fnosPlayer:<account>:<name>`，兼容已有音轨语言和连播键。无账户不读写，不回退共享 local 命名空间。每次 bindAccount／clearAccount 递增代次，旧 handle 即使经历 A→B→A 也不能写入或重置。读取不修写损坏记录；未知字段拒绝。保存失败保留当前 handle 的内存值，并返回未持久化，供后续界面明确提示；不能宣称刷新后仍保留。

reset 只移除当前账户六个已知键，保留其他账户、搜索记录、未知未来字段和历史全局键。中途失败继续尝试其余键并报告未全部持久化；不使用 localStorage.clear。存储访问本身抛错也可安全回退。

历史全局倍速、ASS、字号和 302 值没有账户归属，本模块不自动认领。接入时需明确告知这四项首次使用新账户范围会恢复默认，再由用户保存；不删除旧值，便于旧网页回退。当前未接入，因此线上行为尚未改变。
