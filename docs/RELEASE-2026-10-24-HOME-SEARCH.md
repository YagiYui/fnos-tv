# 首页搜索布局与历史面板

按用户截图反馈，将首页搜索从标题与设置按钮之间移到标题下方，左侧对齐；桌面最大宽度 720px，窄屏随内容区缩放，首页设置保留在标题右侧。

搜索历史不再单独占用首页栏目。点击／聚焦输入框时按原账号历史展开下拉面板，选择历史立即执行既有全库搜索；提交、点击外部、Esc 或键盘焦点离开时收起。首页设置的历史显示开关继续生效，清空只删除当前账号搜索历史，不清当前结果。刷新或详情返回不自动展开，不增加搜索接口调用或修改历史存储规则。

验证：搜索、返回恢复、账户请求三项现有回归通过；构建通过。独立 Edge 用合成 API 验证桌面 1920px／手机 390px、明暗主题、左对齐与宽度、聚焦展开／外部关闭／Esc／Tab 移出、历史点击搜索、清空保留结果、输入法确认不提交及刷新默认收起，页面异常为 0。截图只代表浏览器模拟尺寸，真实手机手感另行验收。
