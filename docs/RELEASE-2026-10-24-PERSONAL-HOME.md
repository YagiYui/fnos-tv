# 独立待看、账号同步与追剧首页

## 行为与边界

- 电影／整部剧集详情增加加入／移出待看，独立于官方收藏。侧栏和首页提供待看入口，每页 21 项，官方详情最多三个并发读取；不可读取的条目可由本人移除。列表返回恢复页码与位置，暖快照先显示再验证，单项失败不阻断其他内容。
- 首页继续观看展示有有效时长时的剩余分钟数。进度到片尾或明确已看且没有新进度时，电影不再推荐；剧集按真实同季相邻编号读取下一集，缺集／季末不跳跃。最多两个并发、同季请求复用；失败引导查看剧集，不冒充可播放的下一集。从“接着看”卡片移除时删除原观看记录，不误删下一集记录。
- 待看剧集可读取官方 local_number_of_episodes，服务器验证媒体权限后记录当前账号的观察基线。首次无更新提示，增加后显示最近七天观察到的集数变化；缺失字段不推断。不是官方上架时间，也不是未看数量；只检查本页待看剧集，移出待看时清理相应观察记录。
- 首页设置控制继续观看／待看（含观察到的剧集变化）／最近入库栏目开关与顺序、媒体库开关与顺序、海报密度及搜索历史展示，提供恢复默认。隐藏入口不改变官方访问权限。视觉与键盘 DOM 顺序一致；最近入库仍使用已确认 create_time DESC 和有限首批加载，不冒称“最近更新”。
- 十一项播放偏好及首页偏好按官方验证账号同步。首次服务器无记录时，只迁入当前账号已保存的设备偏好，不认领历史全局设置；新设备没有配置时不抢先写入默认。服务器已有值优先，缺失项沿用本设备默认；刷新／重新打开播放器读取，切同季相邻集复用已读偏好。读取与媒体元数据并行，不创建额外播放会话。
- 偏好写入合并、串行并校验服务器版本，冲突重新读取后仅合并本次字段，一次重试上限。旧账号请求携带创建时凭据，只能保存原账号；取消后不继续排队或应用迟到响应。同步失败保留当前设备设置并提示，不能声称其他设备已经更新。账号重置按顺序同步默认值，当前播放位置／暂停保留，其他设备刷新后读取。

## 数据与接口

沿用来源模块的官方身份验证、媒体权限读取和独立 data/user-state.sqlite3，不改收藏／观看状态接口，不重分配原共享配置。新增模块 apps/danmu/personal.py 由现有弹幕蓝图注册 `/danmu/personal/watchlist`、`watchlist/<guid>`、`preferences/player|home` 和 `updates/<guid>`。全部从服务端验证结果取得账号，不接受调用者指定账号；待看新增和观察更新先验证媒体访问，清理本人失去访问权限的待看不受阻。

个人配置按类别／范围保留，最多 5000 项，单项 128 KB、每账号合计 16 MB，事务内检查；不会自动删除既有数据。偏好只有已知类型字段，不能保存脚本、媒体票据、凭据或播放地址。播放页诊断仍使用既有白名单。

观察字段证据来自当前官方客户端公开代码中 TV 类型的 local_number_of_episodes 用法，结合官方 item/<guid> 详情读取。观察只存真实返回的非负整数；实际计数语义和素材变化仍列入人工验收。
