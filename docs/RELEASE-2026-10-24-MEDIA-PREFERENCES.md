# F2.2 媒体默认偏好

沿用当前播放器设置补齐本设备字幕语言、默认画质与首选外部播放器。按既有授权自主推进，人工体验继续集中记录，不要求白天实测。

## 行为与回退规则

- 字幕：跟随影片、默认关闭、当前实际 language 代码；不从标题猜语言，保留暂时缺失的已存语言。新开片按精确代码、同语系代码、观看记录、默认轨、首轨回退，无轨为空；明确恢复轨道或关闭快照优先，保证重试保持当前选择。
- 画质：最高可用／4K／1080P／720P／480P／360P。最高沿用当前可用选择器顺序；其他选同档最高码率，缺档先选较低，全部更高时选最低分辨率的最高码率并提示实际结果；只有未知分辨率时保留服务端可用候选，不构造新档位。只保存目标档位，不绑定文件码率；单片切换与失败降画质不写默认。
- 外部播放器：每次选择或当前平台适用的既有入口，弹窗优先展示首选链接，仍需点击；不自动导航协议。Windows PotPlayer 保持 m3u／HTTP，不改注册。平台不匹配时展示每次选择且保留旧值；区分使用桌面 UA 的 iPad，不当成 IINA 设备。软件是否安装和画面／声音须人工验证。

三项修改不立刻改当前轨道或画质，重新开片／切集使用默认。重置扩为十一个已知键，保留历史／其他账号／未知字段，确认文字同步说明延迟生效；部分保存失败仍保留本次内存默认并提示。跨设备同步未实现，不使用共享数据库冒充个人偏好。

## 同批修复

浏览器验证发现 GetPalyUrl 虽有 currentQuality 展示，却在无显式覆盖时始终使用 qualities[0] 和源视频码率。实际 play/play 现优先使用显式覆盖或当前所选可用分辨率／码率，切音轨也保持当前画质；没有新增官方参数。

快速切账号曾出现销毁后的 control 回调访问空 art.layers；旧弹幕 plugin.load 完成也可能改新账户状态。新增播放器实例／代次检查，忽略旧 control、ready、全屏、速率等回调及插件收尾。回归明确复现空实例与等待插件后切换的场景。

独立 Edge 用合成字幕／视频验证首播 subtitle_guid／resolution、菜单保存与下次开播、缺轨／缺档回退、恢复保留关闭字幕、降画质不保存、Windows 首选 m3u 内容与独立原文件准备、不自动启动协议、平台回退、A→B→A、十一项重置和刷新；页面脚本错误为零。另复验原手势重置／原生与旋转全屏／存储失败及 F2.1 恢复与首登继续观看，外部弹窗截图已检查。全程隔离浏览器、假接口，不改真实观看状态。
