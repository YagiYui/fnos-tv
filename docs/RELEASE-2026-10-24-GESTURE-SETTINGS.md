# F2.2 手势设置与恢复默认

用户在具体菜单方案已给出后要求“继续 ToDo，不用停下来”。本批按该方案实施，不再重复等待界面确认；后续常规推进和人工验收分别记录，不把未测项目当成通过。

## 页面行为

现有播放器设置新增“触摸手势”“长按加速倍率（2×／2.5×／3×）”“恢复本账号播放偏好”。两个手势偏好按账号／浏览器保存，新会话正确读取；关闭或改倍率立即取消长按和未提交跳转，恢复原速，不把临时倍率保存为长期速度。桌面也可预先设置，手势只在支持触摸的全屏播放器生效。

恢复默认先显示确认，明确八项范围及生效时机。倍速、字号、自动连播与手势立即恢复；音轨语言优先规则、ASS 样式和 302 在重新打开影片或切集时生效，当前音轨／字幕渲染／播放 URL 不强制重开。保留当前进度与暂停状态，不写观看状态；不清搜索历史、其他账号、弹幕设置或未知未来字段。取消不写任何偏好。

重置增加独立代次，旧菜单与仍在完成的切轨请求不能把清除的值重新写回。确认绑定打开时账号与代次，换账号即关闭；存储部分失败保持本次内存默认并提示刷新后可能恢复原值。全屏确认挂入当前播放器，支持原生与 CSS 旋转全屏，保留现有全屏策略。

本批补齐手势与恢复默认的页面范围。字幕语言、画质、外部播放器偏好及跨设备同步仍待办，F2.2 整项继续保留未完成。
