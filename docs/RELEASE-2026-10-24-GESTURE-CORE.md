# F2.2 手势底层与默认行为清理

本批继续推进尚未完成的 F2.2，不将上一批六项偏好接入算作整项完成。新增菜单具体方案已发出异步选择；在没有答复时先完成手势参数、数据契约、行为回归及现有缺陷修复。

## 已实现与未接入

`installMobileGestures` 新增可选 getPreferences，接受 enabled 布尔和 holdRate 2／2.5／3，坏值按原开启／2 倍回退。长按不会低于当前倍速，结束、取消、多指、退出全屏、失焦和切源都恢复原速。控制器 refresh 立即取消临时加速或尚未提交的横滑；禁用时恢复初始画面滤镜，音量仍保留用户已调整值，不触及系统设置。

发现原 finish 每次创建提示隐藏计时器，却没有取消上一次；多次结束／卸载可能残留计时器。本次 finish 先取消旧计时器，dispose 幂等，重复清理不会再次移除 HUD 或覆盖后续视频滤镜。长按计时器执行前也重新核实全屏、开关和销毁状态。

偏好模块为 gesturesEnabled=true、gestureHoldRate=2 预留严格校验，reset 范围从六个扩为八个已知键，保持其他账号、搜索历史和未知字段。**VideoPlayer 仍使用默认参数安装手势，没有读取这两个新偏好，也没有新增菜单或重置入口。**本批正式页面只能获得默认行为兼容的清理修复，不能在界面上切换手势或倍率。

后续确认方案后，菜单回调、控制器和重置确认均需绑定创建时账号代次；调用 refresh 结束进行中的手势，再应用新值。重置应说明影响范围，不删除观看进度、搜索历史或其他账号设置；未落地的画质／字幕语言／外部播放器偏好与跨设备同步继续保留 TODO。

## 验证

37 项前端回归通过，1 项真实 PGS 素材项跳过；生产构建通过，既有大分块提示仍在。新增实际手势处理器检查覆盖三档倍率、更高原速、不全屏／锁定／控件及边缘避让、禁用和更新、取消待跳转、多指／失焦／暂停／切源、旋转坐标、亮度音量和清理后无监听或计时器。

独立触屏 Edge 使用合成视频和 TouchEvent，验证宽屏触摸、竖屏旋转、2.5×／3×、禁用立即恢复原速、禁用不跳转、取消拖动、失焦恢复与重复清理；页面脚本错误为零。它验证可选参数引擎，不代表已接入菜单，也不是用户真实手机验收。测试未操作真实账户或生产观看状态。
