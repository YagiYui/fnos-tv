# 八项实测问题修复

用户报告的八项问题优先于后续功能演进。本批沿用已授权的自主实施范围，正式环境保留可回退发布，源码、自动验证、发布和用户复验分开记录。

1. 无凭据路由直接进入登录；首次用户信息为空／失败也回到可操作的登录页；注销立即清理账户状态并跳转，取消延迟刷新。
2. 外部播放票据从官方授权的所选文件提取安全 basename，链接末尾和 inline Content-Disposition 使用文件名，保留扩展名，不公开 NAS 完整路径。旧票据没有 filename 字段时仍接受 media。M3U 下载继续保留：用户已确认 PotPlayer 打开文件和直接链接均能播放；本轮待复验的是新链接的显示名称。播放器自行读取媒体内部标题的行为需真机核实。
3. 待看页面提供统一返回入口，直接打开时回首页。
4. 首页轮播箭头移到卡片下方的独立页脚，不遮片名和年份；触摸翻页保留。
5. 进入原生画中画时隐藏原网页的普通字幕、ASS／PGS 覆盖层和弹幕；退出恢复显示，不改字幕选择。浮窗本身仍不承诺网页字幕。
6. 封面失败采用五次有限退避，支持单张点击／键盘、整页失败图片、重新联网及切回可见页面后的重试；成功封面不重载。永久缺失仍显示失败提示，不无限刷请求。本批自动验证模拟瞬时 503，并不证明用户原始封面失败的上游原因已确定。
7. 片库展示范围、总数、每页数量、可点击页码及输入跳转；总数未知保留上下页与明确说明。加载、失败、筛选和返回恢复继续沿用原有请求保护。
8. 播放设置整理为五类；保留全部选择、范围、开关及回调，重建时释放旧面板事件，窄屏内滚动。

自动验证：前端 48 项通过、1 项真实 PGS 素材跳过；构建通过。独立 Edge 合成 API 验证无 Cookie 登录、登录注销、空用户恢复、待看返回、箭头位置、第 3 页 48 张瞬时失败海报重试、跳至第 7 页、390px 分页与设置、嵌套偏好选择、原生画中画字幕隐藏与恢复，页面异常为 0。隔离无网络一次性容器验证新文件名、中文、异常字符、Range／HEAD、鉴权、旧链接、过期与作用域。

部署：仅更新外部播放单文件挂载及前端静态／配套源码。外部模块保留文件 inode；API 因 preload 需要重启主进程，流应用 HUP 载入，不重建容器、不改 Compose、不改 Nginx、不修改媒体和个人数据。更新可能短暂影响正在进行的外部文件流，需客户端重新连接。

回退：先恢复备份外部模块到既有文件并重新加载两个应用，再恢复前端源码及旧 index.html；旧散列静态文件始终保留。旧版本不识别本批新命名票据，回退后新开外部链接需从网页重新获取；不恢复或删除个人数据、媒体与旧播放票据。具体备份路径和上线证据在发布后补充。

用户复验：隐私窗口从首页登录并注销；重新生成外部链接检查 PotPlayer 名称；待看返回；长片名首页翻页；普通／ASS／PGS 各自画中画进出；电影第 3 页滚到底部检查封面和重试；选择页码／跳转及返回恢复；桌面和手机设置分类／音轨／字幕／倍率。以上不以构建或 HTTP 成功代替。
